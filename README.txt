AqylJol — улучшенная версия

ЗАПУСК
Распакуйте архив целиком и откройте index.html в браузере.
Держите HTML, CSS и JS в одной папке. Для карты и веб-шрифтов нужен интернет.
Для стабильного общего хранилища между страницами рекомендуется локальный сервер:
  python -m http.server 8765
После запуска откройте http://localhost:8765

ЧТО ДОБАВЛЕНО
— Новое оформление всех шести страниц, светлая и тёмная темы, мобильная адаптация.
— Иллюстрация автобуса и новая композиция главной страницы.
— Подбор поездки между остановками, обмен направления и оценка длительности.
— Плавная симуляция восьми автобусов с посадкой на остановках.
— Пауза, скорость 1× / 2× / 4×, слежение за автобусом.
— Панель следующей остановки и обратный отсчёт в секундах симуляции.
— Обработка недоступной карты и поддержка настройки уменьшения движения.

О ДАННЫХ
Это демонстрация, не реальные GPS-данные. Координаты остановок приблизительны,
линии не привязаны к дорогам. Время в карточках — исходный демонстрационный
прогноз, а обратный отсчёт на карте относится к ускоренной локальной симуляции.
Подбор поездки использует условные маршруты и 3 минуты между остановками.
Избранное и планы сохраняются только в браузере, перевозчику не отправляются.

ПРОВЕРКИ
Проверен синтаксис JS. Проверено 242176 состояний движения в 16 городах
и 1024 пары остановок. Исходные файлы сверены побайтно.
В браузере проверены карта, пауза, скорость, слежение, подбор поездки,
поиск маршрута, сохранение избранного между страницами, ответ помощника,
светлая/тёмная темы и мобильная ширина 390 px без горизонтального переполнения.
